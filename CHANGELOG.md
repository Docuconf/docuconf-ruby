[CONTRIBUTING.md](CONTRIBUTING.md).

## 0.1.0

First version: typed configuration contracts for [anyway_config](https://github.com/palkan/anyway_config),
implementing spec `v1alpha1`.

### Features

* Declaration metadata on `Anyway::Config` classes: descriptions, secrets, ranges, lengths, RE2 patterns, enums,
  URL schemes, list bounds (including `item_min`/`item_max`), a `:duration` type and file inputs.
* Boot validation of variables and mounted files (config files, TLS key pairs, CA bundles, keystores, text and
  binary files) that reports every problem at once with stable error codes.
* Contract export with `docuconf export` and `rails docuconf:export`.
* Config-file overlays, injector reference checks, contract-first mode and the shared conformance runner.
* The `orders` example app.
